# LFCS Practice — UI prototype

Visual-only Vue 3 + Vite prototype for an LFCS practical exam platform.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Current scope

- Vue 3 + Vite
- Mock LFCS tasks
- Exam sidebar
- Task detail panel
- Visual terminal placeholder
- Timer/progress UI
- No backend
- No database
- No Proxmox integration
- No real terminal connection

Next step: replace the visual terminal with xterm.js and a WebSocket connection to a real lab VM.
